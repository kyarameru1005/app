## 3. カテゴリ一覧画面

### 3.1 画面名
- カテゴリ一覧画面

### 3.2 画面の目的
- 登録済みカテゴリを一覧表示する
- カテゴリ作成画面へ遷移する
- カテゴリ編集画面へ遷移する
- メモ一覧画面へ戻る

### 3.3 表示項目
- 画面タイトル
- カテゴリ作成ボタン
- メモ一覧へ戻るボタン
- カテゴリ一覧
- エラーメッセージ表示欄

### 3.4 一覧表示項目
- `category_name`
- 編集ボタン

### 3.5 入力項目
- なし

### 3.6 ボタン / 操作
- カテゴリ作成ボタン
  - 押下時、カテゴリ作成画面へ遷移する
- 編集ボタン
  - 押下時、対象カテゴリのカテゴリ編集画面へ遷移する
- メモ一覧へ戻るボタン
  - 押下時、メモ一覧画面へ遷移する

### 3.7 初期表示
- 登録済みカテゴリ一覧を表示する
- カテゴリが0件の場合は0件メッセージを表示する

### 3.8 0件時表示
- 「登録されているカテゴリがありません」を表示する

### 3.9 エラー / 例外時
- 未ログインの場合
  - ログイン画面へ遷移
- カテゴリ一覧取得失敗時
  - エラーメッセージを表示する

### 3.10 想定する表示メッセージ

| 種別 | メッセージ |
|---|---|
| 0件時 | 登録されているカテゴリがありません |
| 取得失敗時 | カテゴリ一覧の取得に失敗しました |

## 4. カテゴリ作成画面

### 4.1 画面名
- カテゴリ作成画面

### 4.2 画面の目的
- 新しいカテゴリを登録する

### 4.3 入力項目
- カテゴリ名入力欄

### 4.4 入力項目の仕様
- カテゴリ名
  - 必須
  - 最大100文字
  - 空文字不可
  - 重複不可

### 4.5 表示項目
- 画面タイトル
- カテゴリ名入力欄
- 登録ボタン
- キャンセルボタン
- エラーメッセージ表示欄

### 4.6 ボタン / 操作
- 登録ボタン
  - 入力内容をもとにカテゴリを登録する
  - 登録成功時、カテゴリ一覧画面へ遷移する
- キャンセルボタン
  - 入力内容を破棄してカテゴリ一覧画面へ遷移する

### 4.7 初期表示
- カテゴリ名は空で表示する

### 4.8 入力チェック
- カテゴリ名未入力の場合
  - エラー表示
- カテゴリ名が100文字を超える場合
  - エラー表示
- 既に同名カテゴリが存在する場合
  - エラー表示

### 4.9 エラー / 例外時
- 未ログインの場合
  - ログイン画面へ遷移
- 入力不正の場合
  - 入力欄付近にエラーメッセージを表示
- 登録失敗時
  - エラーメッセージを表示

### 4.10 想定する表示メッセージ

| 種別 | メッセージ |
|---|---|
| カテゴリ名未入力 | カテゴリ名を入力してください |
| カテゴリ名文字数超過 | カテゴリ名は100文字以内で入力してください |
| カテゴリ名重複 | 同じカテゴリ名が既に存在します |
| 登録失敗 | カテゴリの登録に失敗しました |

## 5. カテゴリ編集画面

### 5.1 画面名
- カテゴリ編集画面

### 5.2 画面の目的
- 既存カテゴリを更新する

### 5.3 入力項目
- カテゴリ名入力欄

### 5.4 入力項目の仕様
- カテゴリ名
  - 必須
  - 最大100文字
  - 空文字不可
  - 重複不可

### 5.5 表示項目
- 画面タイトル
- カテゴリ名入力欄
- 更新ボタン
- キャンセルボタン
- エラーメッセージ表示欄

### 5.6 初期表示
- 対象カテゴリの現在のカテゴリ名を表示する

### 5.7 ボタン / 操作
- 更新ボタン
  - 入力内容をもとにカテゴリを更新する
  - 更新成功時、カテゴリ一覧画面へ遷移する
- キャンセルボタン
  - 変更を破棄してカテゴリ一覧画面へ遷移する

### 5.8 入力チェック
- カテゴリ名未入力の場合
  - エラー表示
- カテゴリ名が100文字を超える場合
  - エラー表示
- 既に同名カテゴリが存在する場合
  - エラー表示

### 5.9 エラー / 例外時
- 未ログインの場合
  - ログイン画面へ遷移
- 対象カテゴリが存在しない場合
  - エラーメッセージを表示
- 入力不正の場合
  - 入力欄付近にエラーメッセージを表示
- 更新失敗時
  - エラーメッセージを表示

### 5.10 想定する表示メッセージ

| 種別 | メッセージ |
|---|---|
| カテゴリ名未入力 | カテゴリ名を入力してください |
| カテゴリ名文字数超過 | カテゴリ名は100文字以内で入力してください |
| カテゴリ名重複 | 同じカテゴリ名が既に存在します |
| 対象カテゴリなし | 対象のカテゴリが存在しません |
| 更新失敗 | カテゴリの更新に失敗しました |
